# Product Specification

## Product

Ivan Genes professional portfolio, version 1.

## Primary goal

Help Ivan obtain remote employment as a Senior Software Engineer, Senior Backend Engineer, or Senior
Full-Stack Engineer. Selected freelance collaborations are a secondary goal.

## Audience

- Recruiters evaluating profile fit quickly.
- Engineering managers assessing seniority, architecture experience, and ownership.
- Software engineers participating in technical interviews.

## Positioning

- Primary identity: Senior Software Engineer.
- Specialization: backend architecture, distributed systems, and full-stack development.
- Technical leadership is presented as prior experience, not as the only target role.
- AI-assisted engineering is presented as a structured engineering practice, not as unverified AI
  Engineer experience.

## Value proposition

The portfolio must show that Ivan can design and deliver production software across backend systems,
distributed integrations, enterprise applications, and full-stack products. It must provide enough
technical depth for engineering audiences while remaining easy to scan for recruiters.

## Geography and work model

- Location displayed: Buenos Aires, Argentina.
- Work model displayed: Remote.
- Target market: LATAM and USA.

## Version 1 scope

- English-only public portfolio.
- One-page home with separate case-study routes.
- Five selected projects: NexusMed, NocNoc, Pickit, Yamaha, and Sura Seguros - GPASS.
- Interactive architecture diagrams.
- Backend and Full-Stack resume downloads.
- Email, LinkedIn, and GitHub contact paths.
- Static deployment to `ivangenes.github.io`.

## Out of scope

- Salary expectations.
- Availability status.
- Phone number.
- Declared English proficiency.
- Contact form.
- Analytics.
- CMS or administration panel.
- Blog.
- Internationalization.
- Dark mode.
- Custom domain.
- Client logos, private screenshots, private repositories, or proprietary implementation details.
- AI-powered functionality inside the website.

## Success conditions

- A recruiter can identify Ivan's seniority, specialties, location, and target roles from the first
  viewport.
- An engineering manager can inspect concrete architectural decisions and individual contributions.
- A visitor can open a case study or download either resume without searching through the page.
- Client work is presented accurately, with clear ownership and confidentiality boundaries.
- The deployed site is responsive, accessible, statically generated, and reproducible through CI/CD.
